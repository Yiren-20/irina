National College Smart Car Race Competition (Sep 2022 - Aug 2023)

Second Prize, 2023 East China Division of National Smart Car Competition (Mobile Robot Application track, Team Leader, Awarding Organization: Chinese Association of Automation)

This project was developed for the National College Student Intelligent Vehicle Competition. Using ROS and multiple sensors (LiDAR, RGB camera, IMU, microphone array), it creates a fully autonomous vehicle system capable of mapping, navigation, perception, and speech interaction.

Features

  • Real-time SLAM & Localization: Maps and localizes the vehicle using AMCL and Extended Kalman Filter (EKF).
  • Path Planning & Navigation: Global (Dijkstra / A*) + local (DWA / TEB) planning for smooth navigation and dynamic obstacle avoidance.
  • Object Detection: YOLO-based human detection and recognition.
  • Speech Interaction: Voice command recognition (ASR) and TTS synthesis.
  • Autonomous Driving: Integrates SLAM, path planning, and real-time obstacle detection for self-driving capability.

Innovations

  • Enhanced localization accuracy with EKF.
  • Improved dynamic obstacle avoidance using TEB planner.
  • Real-time human recognition via YOLO deep learning model.

Motion Control

Wheel velocity and steering controlled via a dedicated controller manager.

Applications

Autonomous cars, indoor mobile robots, and service robots.
